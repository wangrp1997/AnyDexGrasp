# Boya适配与AnyDex公开流程对齐结果（2026-11-08）

**本轮完成公开训练实现、映射/闭合语义核对及三组独立控制；整体论文物理复现仍未通过。** 原MSE评分器重新选姿后，旧失败E0实际提起110.990mm并在末态保持双侧承载，但旧成功A0换姿后失载，四件仅1件最终成功。不能将原三件固定姿态失败归给AnyDex算法，也不能把找回一个成功宣称稳定适配。

## 训练与映射到底对齐了什么

直接调用作者原`train_one_epoch`，与当前code100入口比较四头各两个真实批次：初始化、前向、选中输出梯度、Adam后参数、7层BN缓冲、学习率完全相同。435条原raw2261重新经作者canonical480与训练输入逐字节一致。临时CPU模型共8+8次更新，无checkpoint保存/部署，原435条和已训练权重不变。

当前code100是原final-ReLU selected-output MSE、100epoch/Adam/PolyLR，采用发布权重的20输出配置。公开训练脚本默认240输出；作者按test指标保存best，我们固定final100。发布31头的BN计数也表明部分文件不是当前first100/batch128一次batch/epoch的训练历史。**公开资料不能完全还原作者训练史；code100入口不冒充完整实机训练复现。** 之前preactivation模型属于改损失控制，本轮与原损失入口明确分开。

三件原掌帧、flip、raw/extra深度、开闭端点和实际指令复建通过，未发现矩阵或端点接线错误。作者Allegro本身读取闭合起点后，按10次位置增量/每次100ms闭合，再等200ms；没有使用传入的tactile参数，闭合内未调用力矩/触觉修正。因此此前笼统称“缺少作者限力/触觉闭合”不准确。DH3 force70、Inspire角度命令不能直接转换为Boya电机Nm。

Boya参考点由几何模型获得，未实测标定；姿态可重建不证明映射出的抓姿有效。名义闭合参考中点漂移16–51mm，作者也用开手LUT，不能仅凭漂移认定bug。当前垂直抬100mm与原先沿接近方向退4mm再退到pregrasp/throw不同。没有更改这段以免混入多变量。

详见[训练对齐](TRAINING_ALIGNMENT_RESULTS_20261108.md)、[映射/闭合核对](BOYA_MAPPING_CLOSURE_ALIGNMENT_20261108.md)。

第一次代理启动因外层漏OMNI_KIT_ACCEPT_EULA=YES，五路在Kit启动前退出，共0物理步/0试抓，旧日志及RESULTS留v1。明确证明零执行后，v2只改启动环境与输出/协议定位，沿用全部资产；没有重复实际抓取。

## 原损失评分器：重新选姿再执行

新独立`evaluate_boya_original_recipe.py`严格接受已冻结code100报告/四个原MSE头，拒绝preactivation权重。复用原观测/CGR及Boya域，先评分冻结排名再调用完整可见点云几何。四件已知诊断，不声称独立未见测试；没有按结果更换物体或重新训练。

| 对象 | 第一几何准入排名/手型 | 实际结果 |
|---|---|---|
| A0 | rank1 / #6 | 完整2100步；短暂双侧提起56ms后失载，末态源最低点约0.397mm，最终失败 |
| A3 | rank42 / #1 | approach第1175步物体XY推移超过原30mm阈值，任务早停；未闭合/抬升，不是基础设施报错 |
| A6 | rank19 / #7 | 完整2100步，未形成有效提起 |
| E0 | rank0 / #6 | 完整2100步，末态升高110.990mm、源最低点离桌74.094mm、双侧承载保持1.216s，最终成功 |

几何19.002s；四路实际共7475步/38.956s。没有IK/机械臂限制；每件只执行全局排名中首个完整手几何准入候选。A3原早停门保留，不能记成完整试抓或纳入新训练负例。原A0在其他抓姿成功但在这个首选最终失败，E0相反，说明评分器/选姿对结果有直接影响；目前没有稳定优于另一头的结论。

共三组新增**13次实际、26375步**，其中A3一次早停。它们是配对诊断，不合并为总体成功率；原EGAD12的1/12、原三件0/3及全部失败保持。训练实现对齐没有自动消除Boya物理标定、数据分布/监督覆盖、评分泛化及源几何近似问题。32-fit的80输出槽有17个无标签、20个仅1–2条，属于支持不足证据，不证明唯一原因。
