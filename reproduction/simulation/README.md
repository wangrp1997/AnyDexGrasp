## 原方法与观察链路

真实仿真RGB-D → 原identity+10增强表示网络 → 原4发布决策头 → 原碰撞 → 原top10/top1 → 原手几何 → 两驱动/腕部物理执行已经连通。未将物体类别、分割标签、物体真值位姿或预设抓姿送入网络。

原11分支生成323候选，学习评分top400经原碰撞后111准入；原top1为type4、63mm开度、40mm深度、寄存器[95,100]。全部动态版本执行同一top1；物体尺寸、摆放、相机、网络与原筛选门槛不变。11分支15.980s，含加载/评分/碰撞runner内部35.647s；不能把它当观察到抬升耗时。

原2D→12D公式直接复用。独立几何适配保留13原实体STL/质量/惯性；helperless版只略去第三指3.673e-6rad常量差。355预抓取+96闭合姿态全部三角形顶点实测最大误差0.122µm。精确V1的零质量辅助关节在Bullet动态中锁定，参考与失败证据保留。

## 为什么先前抓起仍未验收，最后如何解决

原公式定义二维配置子空间。早期0.8Nm传动数值上限会允许结构关系滑移，它并非作者提供的机械离合器/电机标定。后续明确采用理想刚性结构假设，将传动数值上限预先设为100Nm；主动电机仍限0.6/0.3Nm、腕部仍每行30N/Nm。该100是工程数值尺度，不是严格反力定理或硬件参数。单独此改动仍失败；增加inner迭代也未解决。

随后只细化积分时间步长，保留inner20、物理时长、连续控制函数、接触几何、出力与判据。全部实际积分步均保存，没有通过隐藏子步漏记峰值：

| 时间步 | 最大传动残差rad | 最大关节速度rad/s | 末态升高mm | 原判据 |
|---|---:|---:|---:|---|
| 1/240 s | 0.162744 | 2.711203 | 90.752 | 未通过 |
| 1/480 s | 0.050475 | 2.604680 | 89.806 | 未通过 |
| 1/960 s | 0.011286 | 1.885347 | 88.880 | 未通过 |
| 1/1920 s | 0.001712 | 1.377069 | 88.518 | 通过 |
| 1/3840 s | 0.000454 | 1.261935 | 88.592 | 通过 |

判据始终为残差<0.01rad、峰速<1.5rad/s、腕COM误差<2mm、有限状态与原电机/结构反力界，加实际离桌>50mm、最低点>40mm及末态正法向接触。原失败标签未回改。

1920/3840腕误差分别0.1042/0.0521mm，结构反力峰0.9486/1.0827Nm，远未触及100Nm数值上限。细化后的残差和末态高度表现出收敛；不是通过增大电机出力或放宽判据得到成功。只验证此场景，不能据此证明任意接触状态均收敛。

采样绝对校正功proxy从240Hz的0.094963J降至1920/3840Hz的0.011573/0.007674J。它不是严格能量上界或被动性证明，不能声称已排除一切数值做功。推导及物理含义见[KINEMATIC_CONSTRAINT_MODEL.md](KINEMATIC_CONSTRAINT_MODEL.md)。
