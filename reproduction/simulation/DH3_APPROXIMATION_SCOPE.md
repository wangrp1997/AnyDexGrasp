# DH3 受载闭合仿真近似的范围

本轮目标是尽快获得一个可运行、可解释的受载闭合模型，用于检查原抓姿在接触后的表现。这里的模型是公开结构资料启发的 **simulation proxy（仿真替代模型）**，尚未经过实机辨识；所选参数属于明确声明的仿真假设。

AnyDexGrasp 原方法生成并筛选抓取候选，随后在真机上调用 DH3 硬件完成闭合。其公开推理流程不以弹簧刚度、预紧量、丝杆导程或被动关节摩擦等参数为输入。真实硬件承担了接触后的机械响应，原代码并未提供一套可直接移植且已标定的 DH3 受载动力学。因此，新增 proxy 属于我们的仿真适配层，不能归为作者已发布的原始动力学实现。

新增近似采用 **共同驱动轴加三路弹簧耦合**：同一驱动轴向三根手指传递闭合运动，每路弹性耦合允许相应手指在受阻时产生相对偏移；弹簧同时向共同驱动轴施加反作用，使受载手指能够影响共同驱动的运动。这不是给三根手指各加一个独立主动电机，也不是已确认的商用 DH3 自由差动机构。公开资料不足以把它与论文所称的四自由度、两电机逐坐标对应，故不能称为真实商用 DH3 或其 4DoF 机构的克隆。

几何方面保留源候选姿态和 13 个原有实体。各指内部 tip/outlet 与本指主弯曲坐标之间，仍沿用旧模型的局部 affine（仿射）关系。新增弹性仅作用于共同轴与各指分支之间，**尚未增加指内额外弯曲能力**；例如近节被物体阻挡后，远节沿独立被动坐标继续弯曲的机制，当前模型并没有实现。因而分支受阻后的差异运动，不能作为真实指内自适应机构已被复现的证据。

后续结果应标为“原 AnyDex 候选在所声明 DH3 仿真 proxy 下的执行结果”。是否提起物体、传动偏差、接触与控制代价分别报告，并保留既有刚性模型及失败记录。这些结果可用于判断该近似是否有助于接触后的抓取，但不能据此宣称硬件已校准、真实 DH3 能力已验证，或将其成功比例作为原论文复现成功率。
